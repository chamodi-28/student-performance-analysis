# Student Performance Data Analysis

## Project Overview

This project analyzes student academic performance using Microsoft Excel.

## Objectives

- Analyze student performance
- Calculate average marks
- Analyze attendance
- Compare performance by gender
- Create a BI dashboard

## Tools

- Microsoft Excel
- PivotTables
- Excel formulas
- Charts

## Dataset

The dataset contains student information including attendance,
assignment marks, examination marks and final marks.

## Key Analysis

- Average student performance
- Pass percentage
- Gender-based performance
- Attendance and performance
- Performance levels

## Dashboard

The project includes an interactive Excel dashboard
for visualizing student performance.
